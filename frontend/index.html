About This Forecast

01

Source

Monthly station records for Addis Ababa, averaged from raw daily/period readings into five climate variables per month.

02

Method

A separate seasonal ARIMA (SARIMAX) model is fit per variable, tuned to a 12-month cycle so it can learn Kiremt, Belg, and Bega on its own.

03

Uncertainty

The shaded band on each chart is an 80% confidence interval — the model's honest range, not a single overconfident number.
